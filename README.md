# Notes From a Passive-Aggressive Fridge

Entry for the [make.fun](https://make.fun/r/41fw6r6c) competition **Notes From a Passive-Aggressive Fridge** (`u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7`).

## Usage

Runs on Node.js 22.18+ and writes a deterministic single-line note (<= 200 UTF-8 characters) to `/output/entry.txt`:

```bash
node main.ts
```
